# EL ARRECIFE · primera prueba privada

Esta es una aventura ilustrada en primera persona. Juega con clic o toque. En móvil, coloca el dispositivo en horizontal. Explora libremente y cuenta qué intentas hacer; no necesitas leer ninguna solución antes de empezar.

## Abrir la versión Web

1. Extrae todo el ZIP en una carpeta.
2. En esa carpeta, ejecuta `python3 -m http.server 8767`.
3. Abre `http://127.0.0.1:8767/` en un navegador actual. No abras `index.html` con `file://`.

Para compartirla en otro equipo, quien organice la prueba debe servir estos mismos archivos por HTTP(S) desde una dirección accesible para ese equipo. La carpeta puede estar en una subruta. Esta build no se ha publicado en el dominio oficial.

El progreso se guarda en el navegador de este dispositivo. **No hay copia en la nube**. Si borras los datos del sitio o cambias de navegador, puedes perderlo; el menú «Partidas» permite descargar una copia manual. Si algo falla, apunta la pantalla, la acción y el navegador, y comunícaselo a quien organiza la prueba. `MANIFEST.json` identifica la versión, el commit y la versión de Godot.
