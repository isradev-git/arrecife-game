# Sota 0.1 stable

Modelo 12 / atlas articulada_v8, designado por el autor el 16 de octubre de 2026 como la mejor versión y base estable. Esta aprobación no declara terminado el movimiento: pide pulir su rigidez.

Copia exacta de fuentes, controlador, integración, generador y PNG/JSON necesarios para recuperar Sota. SHA256.json identifica los archivos. Para restaurar, copiar las rutas bajo godot/ sobre las mismas rutas del proyecto, importar Godot y volver a exportar Web. No es un juego independiente ni incluye el resto del escenario. Los atlas originales v8 permanecen también en su ruta.
